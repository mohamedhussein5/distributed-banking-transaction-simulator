# Distributed Banking Transaction Simulator

A group academic simulation using Python TCP sockets, threaded transaction handling, SQLite, account locks and backup-log replication. The report documents a three-node virtual-machine cluster and performance evaluation.

## Technologies and skills

Python, TCP sockets, JSON, SQLite, concurrency, replication, MPI and virtual machines.

## Authorship and scope

My documented responsibility was data storage, backup replication and the administration console. Other components were developed by teammates.
